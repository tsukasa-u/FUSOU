👉 http://localhost:8085/ で開く

使い方ガイド

1. 画面上の島（アッツ・キスカ等）をペンツールやブラシでなぞって描きます。
2. 下書き読込 を押すと、既存の抽出結果が読み込まれ、消しゴムで削る作業から始められます。
3. 完了したら右上の マスクPNG保存 を押し、ダウンロードしたファイルをプロジェクトの src/assets/map/3-5/land_mask.png に配置するだけで反映完了です！
