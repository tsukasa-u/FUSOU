## 1. 夜戦基本攻撃力 (Night Base Attack Power)

### 1-1. 通常艦（水上艦・潜水艦）

水上艦および潜水艦の夜戦基本攻撃力は、火力と雷装を単純合算した値に改修補正を加えたものになります。

$$
\text{夜戦基本攻撃力} = \text{素火力} + \text{装備火力} + \text{素雷装} + \text{装備雷装} + \text{改修夜戦補正} + \text{夜間触接補正}
$$

- **夜間触接補正**: 九八式水上偵察機(夜連)等の夜偵が触接に成功した場合、**一律 +5** の加算ボーナス。
- **対地目標への例外**: 敵が陸上型深海棲艦の場合、**雷装値（素雷装・装備雷装・改修雷装）はすべて 0 扱い**となります。

### 1-2. 夜間空母攻撃力（CVCI / 夜間航空攻撃）

正規空母・装航・軽空母が夜間戦闘機（夜戦）・夜間攻撃機（夜攻）・夜間作戦航空要員を搭載して夜戦に参加する場合、以下の専用式が適用されます。

$$
\text{夜間空母基本攻撃力} = \text{素火力} + \text{装備火力} + \sum (\text{夜間機雷装}) + \sum (\text{夜間機爆装}) + \text{夜間機改修補正} + \text{機体スロット補正} + \text{夜間触接(+5)}
$$

- **夜間機スロット補正**:
  $$
  \text{スロット補正} = \sum_{\text{夜間機}} \left( \text{種別係数} \times \text{搭載機数} + \sqrt{\text{改修★}} \times \text{係数} \right)
  $$
- 対応空母（Saratoga Mk.II、赤城改二戊、加賀改二戊、龍鳳改二戊等）は要員なしで夜間発艦可能。通常空母は「夜間作戦航空要員（+熟練甲板員）」の装備が必須。

### 1-3. 改修強化値（夜戦）の主な係数

| 装備種別 | 改修係数 | 備考 |
| :--- | :---: | :--- |
| **小口径主砲 / 中口径主砲 / 大口径主砲** | $1.0 \times \sqrt{★}$ | 昼戦と同等 |
| **魚雷 (水上艦・潜水艦魚雷)** | $1.2 \times \sqrt{★}$ | 高い夜戦雷圧補正 |
| **副砲** | $1.0 \times \sqrt{★}$ | |
| **対空機銃** | $1.2 \times \sqrt{★}$ | KCWIKI/作戦室検証 |
| **探照灯 / 大型探照灯** | $1.0 \times \sqrt{★}$ | 自艦の夜戦火力に加算 |

## 2. キャップ処理 (Soft Cap)

### 2-1. 夜戦キャップ値: **360**
- 歴史的変遷: 300 → **360**（全サイト一致）

### 2-2. キャップ前補正

$$
\text{キャップ前攻撃力} = \text{基本攻撃力} \times \text{交戦形態補正} \times \text{損傷補正} + \text{加算補正}
$$

- **陣形補正**: 夜戦では通常の単縦〜単横陣形補正は**適用されません**（1.0倍固定）。ただし連合艦隊・警戒陣・特殊攻撃では専用補正が適用されます。
- **交戦形態補正**: 昼戦から引き継いだ交戦形態（同航1.0 / 反航0.8 / T有利1.2 / T不利0.6）がそのまま乗算されます。

### 2-3. 損傷度補正（夜戦）

| 損傷状態 | 補正 | 行動制限 |
| :--- | :---: | :--- |
| **小破以下** (HP > 50%) | 1.00 | 通常攻撃・特殊攻撃可能 |
| **中破** (25% < HP <= 50%) | 0.70 | 通常艦・夜間空母ともに攻撃力低下 |
| **大破** (HP <= 25%) | - | **攻撃不能**（手番スキップ） |

## 3. 新夜戦カットイン判定優先度カスケード (Cascade Priority)

同一艦娘が複数のカットイン発動条件を同時に満たしている場合、以下の**厳密な優先度順（上から順に判定）**で抽選が行われます。上位のカットインが不発となった場合にのみ、下位の判定へ遷移します。

```
[判定開始]
   │
   ├─ [優先度 1] 潜水艦隊特殊攻撃（潜水母艦旗艦または潜水艦隊）
   │     └─ 成功: 潜水艦隊攻撃発動 / 失敗: 次へ
   ├─ [優先度 2] 大和型/金剛型夜戦特殊攻撃（僚艦夜戦突撃 / 突撃！友軍艦隊）
   │     └─ 成功: 特殊砲撃発動 / 失敗: 次へ
   ├─ [優先度 3] 魚魚水 CI（魚雷2 + 水雷戦隊 熟練見張員）
   │     └─ 成功: 1.5x x 2回 / 失敗: 次へ
   ├─ [優先度 4] 魚見電 CI（魚雷 + 水雷見張員 + 電探）
   │     └─ 成功: 1.2x ~ 1.85x x 2回 / 失敗: 次へ
   ├─ [優先度 5] 魚魚魚 CI（魚雷2基以上の従来魚雷CI）
   │     └─ 成功: 1.5x x 2回 / 失敗: 次へ
   ├─ [優先度 6] 主魚電 CI（主砲 + 魚雷 + 電探）
   │     └─ 成功: 1.3x x 2回 / 失敗: 次へ
   ├─ [優先度 7] 主副 CI（主砲2 + 副砲1）
   │     └─ 成功: 1.75x x 1回 / 失敗: 次へ
   ├─ [優先度 8] 主砲 CI（主砲3基以上）
   │     └─ 成功: 2.0x x 1回 / 失敗: 次へ
   ├─ [優先度 9] 連撃（主砲2基以上、水偵等）
   │     └─ 成功: 1.2x x 2回 / 失敗: 通常単発攻撃
   ▼
[通常単発攻撃]
```

### 4-3. 潜水艦隊特殊攻撃（潜水艦隊攻撃）

- **発動条件**: 梯形陣（または単横陣）、旗艦小破以下、随伴潜水艦小破以下
- **倍率**: 旗艦および随伴潜水艦が **1.2x 〜 1.35x × 2回攻撃**（カットイン演出を伴う強力な雷撃斉射）

- **大和型改二「突撃！友軍艦隊」**: 大和改二/武蔵改二。昼戦で特殊砲撃を使用していない場合、夜戦で強烈な斉射を発動。

## 5. カットイン発動率のロジスティクス回帰モデル

カットイン発動率は、運（Luck）を中心としたロジスティクス式で決定されます。

$$
P_{\text{CI}} = \lfloor \text{運項} \rfloor + \text{配置補正} + \text{損傷補正} + \text{装備補正}
$$

### 5-1. 運項の基本式 (KCWIKI / 作戦室)

$$
\text{運項} = \left\lfloor \frac{\sqrt{\text{運}} \times 15 + \text{Lv} \times 0.1}{\text{種別分母}} \right\rfloor
$$

- **種別分母**: 魚雷CI（約 0.85〜0.9）、主砲CI（約 0.95）、主魚電（約 0.8）
- **運キャップ**: 運50〜60付近で発動率の伸びが緩やかになるソフトキャップ構造。

### 5-2. 各種加算補正

| 項目 | 補正値 | 備考 |
| :--- | :---: | :--- |
| **旗艦配置ボーナス** | **+12.5% ~ +15%** | 旗艦はCI発動率が大幅上昇 |
| **中破状態** | **+15% ~ +18%** | いわゆる「中破ブースト」 |
| **熟練見張員** | **+5% ~ +8%** | 駆逐・巡洋艦で発動率底上げ |
| **探照灯 (点灯時)** | **+5%** | 味方全体のCI率上昇 |
| **照明弾 (点灯時)** | **+4% ~ +5%** | 味方全体のCI率上昇 |

## 6. 夜戦支援装備の効果

### 6-1. 夜偵（九八式水上偵察機(夜連)等）
- **発動条件**: 航空劣勢以上、かつ夜偵搭載艦が小破以下
- **発動率**: 艦娘Lvおよび夜偵の機体索敵値に依存（Lv99で約 $70\% \sim 80\%$）
- **効果**: **基本攻撃力 +5、命中率 +10%、クリティカル率 +10%**（全味方艦に適用）

### 6-2. 探照灯 / 大型探照灯
- **点灯条件**: 搭載艦が小破以上（大破時は点灯不可）
- **効果**:
  - 味方艦隊全体の夜戦命中率 **+5%**、CI発動率 **+5%**
  - **敵艦隊全体の夜戦カットイン発動率を抑制（約 -5%〜-10%）**
  - **被ターゲット率上昇（ヘイト誘導）**: 敵の夜戦攻撃が探照灯艦へ集中しやすくなるデコイ効果
  - 自艦の回避率ペナルティ（大型探照灯は改修★maxでペナルティ大幅軽減）

### 6-3. 照明弾
- **発動率**: 1基あたり約 **65%**（複数搭載で発動率向上）
- **効果**: 味方命中率 **+10%**、味方CI発動率 **+5%**、**敵夜戦CI発動率を約 -10% 抑制**
