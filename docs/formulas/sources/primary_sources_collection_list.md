- **誰得艦これ** (`https://ameblo.jp/daretokukancolle/`):
  フィット砲、改修命中、夜戦カットイン等の統計的実証の第一人者。

  装備改修値によるステータス上昇の網羅的記録。

### コミュニティ・生データ集約プラットフォーム
- **艦これ攻略Wiki (WIKIWIKI.jp)** (`https://wikiwiki.jp/kancolle/`):
  各検証者の成果が合意形成を経てまとめられるハブ。各ページの注釈や砂場に一次ソースリンクが豊富。
- **Google スプレッドシート (公開シート群)**:
  出撃生ログ（Raw Data）、分割表、回帰分析シートが共有される一次データの宝庫。
- **X (Twitter) ハッシュタグ `#艦これ検証`**:
  新仕様・新装備の速報的検証スレッド。
- **NGA 艦娘板 (bbs.nga.cn)**:
  中国語圏の検証コミュニティ。確率分布や内部コード解析に基づく理論的考察スレッドが多数存在。
