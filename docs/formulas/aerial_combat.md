## 1. 制空値計算 (Air Superiority Value)

### 1-1. 基本制空値

$$
\text{スロット制空値} = \lfloor (\text{装備対空値} + \text{改修補正}) \times \sqrt{\text{現在搭載機数}} + \text{熟練度ボーナス} \rfloor
$$

- **装備対空値**: 航空機装備自体の対空ステータス（艦娘本体の素対空は含まない）
- **現在搭載機数**: 各スロットに現存する機体数（損耗により減少）
- **艦隊総制空値**: 自艦隊の全艦・全スロットの制空値の単純総和

### 1-2. 改修による制空値ボーナス

| 装備種別 | 改修係数 | 適用方法 |
| :--- | :---: | :--- |
| **艦上戦闘機・水上戦闘機・陸上戦闘機** | $0.2 \times ★$ | 装備対空値に直接加算（線形） |
| **艦上爆撃機 (爆戦含む)** | $0.25 \times ★$ | 装備対空値に直接加算（線形） |

### 1-3. 航空機熟練度ボーナス

熟練度ボーナスは「内部熟練度平方根項」と「熟練度帯（記号）ボーナス」の合算です。

$$
\text{熟練度ボーナス} = \sqrt{\frac{\text{内部熟練度}}{10}} + \text{熟練度帯定数}
$$

#### 内部熟練度と表示記号

| 表示記号 | 内部熟練度 | $\sqrt{\text{内部}/10}$ 概算値 |
| :---: | :---: | :---: |
| なし | 0 ～ 9 | 0.00 ～ 0.94 |
| \| | 10 ～ 24 | 1.00 ～ 1.54 |
| \|\| | 25 ～ 39 | 1.58 ～ 1.97 |
| \|\|\| | 40 ～ 54 | 2.00 ～ 2.32 |
| //// | 55 ～ 69 | 2.34 ～ 2.62 |
| \\\\ | 70 ～ 84 | 2.64 ～ 2.89 |
| \\\\\\ | 85 ～ 99 | 2.91 ～ 3.14 |
| **>> (MAX)** | **100 ～ 120** | **3.16 ～ 3.46** |

#### 熟練度帯定数（最大熟練度 >> の場合）

| 装備種別 | 熟練度 >> での固定加算値 |
| :--- | :---: |
| **艦上戦闘機・水上戦闘機** | **+22** |
| **水上爆撃機 (瑞雲系等)** | **+6** |
| **艦上攻撃機・艦上爆撃機** | **+1** |

### 1-4. 制空状態の判定基準

| 制空状態 | 判定条件 | Stage 1 自機損耗率 | 弾着CI発動 | 夜偵触接 |
| :--- | :--- | :---: | :---: | :---: |
| **制空権確保 (AS+)** | 自軍制空 $\ge$ 敵軍 $\times 3.0$ | 最少 (0%〜10%) | 〇 (高確率) | 〇 |
| **航空優勢 (AS)** | 自軍制空 $\ge$ 敵軍 $\times 1.5$ | 少 (5%〜20%) | 〇 (通常) | 〇 |
| **航空均衡 (AP)** | 双方上記条件を満たさず | 中 (10%〜40%) | × | × |
| **航空劣勢 (AD)** | 自軍制空 $\le$ 敵軍 $/ 1.5$ | 大 (20%〜60%) | × | 敵のみ〇 |
| **制空権喪失 (AI)** | 自軍制空 $\le$ 敵軍 $/ 3.0$ | 最大 (30%〜80%) | 敵のみ〇 | 敵のみ〇 |

### 1-5. 基地航空隊の偵察機補正

$$
\text{補正後基地制空値} = \lfloor \text{基地合計制空値} \times \text{偵察機補正係数} \rfloor
$$

| 偵察機種別 | 出撃時補正 | 防空時補正 |
| :--- | :---: | :---: |
| **陸上偵察機 (偵察索敵 $\ge 9$)** | **1.18x** | **1.24x** |
| **陸上偵察機 (偵察索敵 $= 8$)** | **1.15x** | **1.21x** |
| **二式陸上偵察機(熟練)** | **1.24x** | **1.24x** |
| **大型飛行艇 (二式大艇等)** | **1.12x** | **1.16x** |

## 2. 航空戦 Stage 1・Stage 2

### 2-1. Stage 1: 制空戦と自機損耗

両軍の制空状態に応じて、各スロットの航空機が割合で損耗します。
自軍の制空権確保時は損耗が極めて軽微となり、喪失時は艦載機スロットが枯渇（全滅）するリスクが跳ね上がります。

### 2-2. 触接の2段階選定システム (Contact Selection)

航空戦での与ダメージを劇的に引き上げる「触接」は、**発生判定（Stage 1）** と **機体選定（Stage 2）** の 2 段階で判定されます。

#### 第1段階: 触接発生判定
艦隊内の水上偵察機・艦上偵察機・飛行艇の索敵値とスロット機数から発生確率が計算されます。航空優勢以上で判定。

$$
P_{\text{start}} = \sum_{\text{偵察機}} \left( 0.04 \times \text{装備索敵値} \times \sqrt{\text{機数}} \right)
$$

#### 第2段階: 触接機体の選定と攻撃力倍率
発生判定に成功した場合、スロットの上から順に各機体の **命中値** に応じた優先度で選定されます。

| 触接機体の命中値 | 触接攻撃力倍率 | 代表機体 |
| :---: | :---: | :--- |
| **命中 +3 以上** | **x 1.20** | 二式艦上偵察機、彩雲(カロリン空)、紫雲 |
| **命中 +2** | **x 1.17** | 零式水上偵察機11型乙(熟練)、九八式水偵(夜連) |
| **命中 +1 以下** | **x 1.12** | 通常水偵、零式水上観測機 |

選定された倍率は、航空戦 Stage 3 の空爆ダメージ全体に乗算されます。

## 3. 対空砲火 (Stage 2: Anti-Air Fire)

敵航空機の空爆直前に、迎撃側の各艦が対空砲火を実施して敵機を撃墜します。

### 3-1. 撃墜数の決定アルゴリズム

迎撃艦の中から 1 隻がランダムに防空担当艦として選ばれ、以下の合算で撃墜数が決定されます。

$$
\text{総撃墜数} = \lfloor \text{割合撃墜} \rfloor + \lfloor \text{固定撃墜} \rfloor + \text{対空CI保証撃墜}
$$

1. **割合撃墜 (Proportional Shot-down)**:
   $$
   \text{割合撃墜数} = \lfloor \text{敵スロット機数} \times \frac{\text{迎撃艦の加重対空値}}{400} \rfloor
   $$
2. **固定撃墜 (Fixed Shot-down)**:
   $$
   \text{固定撃墜数} = \lfloor (\text{加重対空} + \text{艦隊防空値}) \times \text{陣形防空補正} \times \frac{\text{対空CI変動ボーナス}}{10} \rfloor
   $$
3. **対空CI保証撃墜**:
   対空カットインが発動した場合、敵スロット機数を最低限固定で撃墜する保証値（+1〜+11機）。

## 4. 加重対空値と艦隊防空値

### 4-1. 加重対空値（個艦防空値）

各艦娘自身が持つ防空能力です。

$$
\text{加重対空値} = \text{素対空} + \sum (\text{装備対空} \times \text{装備種別係数} + \text{改修係数} \times \sqrt{★})
$$

| 装備種別 | 装備係数 | 改修係数 |
| :--- | :---: | :---: |
| **高角砲 (主砲/副砲)** | **x 2** | $1.0 \times \sqrt{★}$ |
| **対空機銃** | **x 3** | $1.4 \times \sqrt{★}$ |
| **対空電探** | **x 1.5** | $0.0$ |
| **特殊高角砲 (秋月砲等)** | **x 2** | $1.0 \times \sqrt{★}$ |

### 4-2. 艦隊防空値（艦隊全体への寄与）

艦隊全体を守るための防空支援値です。

$$
\text{艦隊防空値} = \lfloor \sum (\text{装備対空} \times \text{艦隊防空係数}) \rfloor \times \text{陣形補正}
$$

| 陣形 | 艦隊防空陣形補正 |
| :--- | :---: |
| **単縦陣 / 複縦陣 / 梯形陣 / 単横陣** | **1.0** |
| **輪形陣** | **1.4**（艦隊防空40%向上） |
| **第三警戒航行序列 (連合防空)** | **1.5** |

## 5. 対空噴進弾幕システム (Rocket Barrage)

「12cm30連装噴進砲改二」を装備した航戦・航巡・軽空母・水母が空襲を受ける際、専用の対空ロケット斉射演出とともに**航空爆撃ダメージを完全無効化（0ダメージ）**するシステムです。

### 5-1. 弾幕発動率の計算式

$$
P_{\text{barrage}} = \min\left(100\%, \frac{\text{加重対空値} + \text{改修ボーナス} + \text{運}}{282} \times 100\%\right)
$$

- **必要装備**: **12cm30連装噴進砲改二**（1基以上装備）
- **対象艦種**: 航空戦艦（伊勢型、扶桑型）、航空巡洋艦（最上型、利根型）、軽空母、水上機母艦
- **2基装備ボーナス**: 噴進砲改二を2基搭載することで、発動率が大幅に上昇（改修★maxと運の合算で発動率 **100%** に到達可能）。
- **発動時の効果**: その空襲において自艦に対するすべての航空爆撃ダメージが **0（完全無傷）** となります。

## 6. 対空連合艦隊における迎撃仕様

連合艦隊（機動部隊・水上部隊・輸送部隊）における航空戦では、以下のルールで防空が処理されます。

1. **防空担当艦の選定**:
   空襲を受けた際、第1艦隊および第2艦隊の全12隻の中から防空担当艦が抽選されます。
2. **艦隊防空値の合算**:
   第1艦隊と第2艦隊の全艦の対空装備から艦隊防空値が合算され、第三警戒航行序列（防空陣形）では 1.5 倍の強烈な防空ボーナスが味方全体にかかります。
3. **対空CIの共有**:
   第1艦隊・第2艦隊のいずれの艦娘が対空カットインを発動しても、艦隊全体の敵機迎撃に保証撃墜と変動ボーナスが適用されます。
