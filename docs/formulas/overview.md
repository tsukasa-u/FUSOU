# 艦これ戦闘計算式 総合ドキュメント・ポータル

## 1. 概要とアプローチ

本ドキュメント群は、艦これ（艦隊これくしょん）において長年にわたり国内外の有志検証者によって解明・推定されてきた各種戦闘計算式を、**一次検証者への最大限の敬意と客観性**をもって体系化した総合ポータルです。

### コミュニティ知見の尊重と一次情報源の重視
艦これの戦闘仕様は運営公式から詳細な計算式が開示されないため、コミュニティの検証者が莫大な出撃数と資材を投じて導き出した一次検証データ（Primary Sources）がすべての基盤となっています。

- **一次情報源の尊重**: 既存の他シミュレータコードからの逆引き転載ではなく、検証者ご本人が公開した一次ポスト・スプレッドシート・検証スレッドの知見を参照・整理しています。
- **計算パイプラインの体系化**: 入力ステータスから陣形・交戦形態・キャップ処理・防御減算を経て最終ダメージに至る一連の決定論的・確率論的フローを網羅的に整理しています。
- **情報源一覧**: 詳細は [検証式の情報源・収集手法および検証倫理方針](/docs/formulas/sources/verification_sources_and_methodology) を参照してください。

## 4. 全体共通ダメージ計算フローとキャップ値一覧

すべての戦闘フェーズで共通する標準的なダメージ算出パイプラインです。

```
[Step 1] 基本攻撃力の算出（砲撃・雷撃・航空・対潜で個別定義）
    │
[Step 2] キャップ前補正の適用（乗算・加算）
    ├─ × 交戦形態補正（同航戦:1.0 / 反航戦:0.8 / T字有利:1.2 / T字不利:0.6）
    ├─ × 陣形補正（単縦:1.0 / 複縦:0.8 / 輪形:0.7 / 梯形:0.75 / 単横:0.6）
    ├─ × 損傷度補正（小破以下:1.0 / 中破:0.7 / 大破:0.4）
    ├─ × 対地乗算特効（大発系・内火艇・士魂隊）
    └─ ＋ 加算系特効（WG42・対地噴進砲等）
    │
[Step 3] 攻撃力キャップ処理
    ├─ キャップ値以下: そのまま
    └─ キャップ値超過: Cap + √(攻撃力 - Cap)
    │
[Step 4] キャップ後補正の適用（乗算）
    ├─ × 弾着観測射撃 / 戦爆連合CI倍率
    ├─ × 徹甲弾補正（1.08x ~ 1.15x）
    ├─ × クリティカル補正（1.5x × 熟練度クリティカル補正）
    ├─ × 特殊攻撃倍率（Nelson Touch / ながもん一斉射等）
    └─ × 集積地棲姫キャップ後特効（2.0x ~ 3.0x）
    │
[Step 5] 防御力減算・最終与ダメージ算定
    ├─ 実効装甲 = 装甲 × 0.7 + 装甲乱数(0 ~ 装甲-1) × 0.6
    ├─ 貫通ダメージ = floor((最終攻撃力 - 実効装甲) × 弾薬量補正)
    └─ 装甲未貫通時: 割合ダメージ（カスダメ: 残HPの約6%~14%）
```
